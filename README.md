This project is a TCP/IP Chat Application developed in Python, featuring a graphical user interface 
(GUI) built using the tkinter library. It enables real-time, two-way communication between a client and server using TCP sockets, allowing users to exchange text messages over a 
network. The application includes key GUI elements such as input fields, send buttons, and a display
area to show chat history. It uses Python’s socket module for networking and threading to handle incoming messages in the background, ensuring that the GUI remains 
responsive during communication. Users can enter the server’s IP address and port to establish a connection, and both client and server applications are equipped with basic input validation and 
error handling to manage cases like invalid IPs, connection failures, or empty messages. The project was designed with simplicity and clarity in mind, making it easy to use and understand, 
especially for educational and demonstration purposes. A GitHub repository is maintained with at least 15 meaningful commits showing the progression of development from initial setup to
complete functionality, and includes setup instructions, sample screenshots of the GUI, and detailed in-code comments. A PowerPoint presentation consisting of 10 slides is also provided to 
explain the project’s objectives, architectural design, GUI layout, socket programming logic, threading implementation, and the challenges encountered during development. The application 
has been tested locally and across a LAN to confirm reliable message delivery, and while currently designed for one client at a time, it can be extended to support multiple clients with 
further development. Potential future improvements include adding encryption for secure messaging, multi-client support with threading on the server side, and upgrading the GUI with 
libraries like PyQt for a more modern look. This chat application provides a practical example of how network communication and GUI programming can be integrated in Python, meeting the 
project requirements of using TCP/IP, exception handling, GUI design, and professional documentation.
